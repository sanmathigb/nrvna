Submit now.
Run the model later.

Unix-like primitives for durable local inference. No always-on server.

Give nrvnad a GGUF model and a directory. That directory becomes the workspace. Each job is a folder inside it. Moving that folder changes the job state. Results stay there as files.

Experimental developer preview. Tests cover the filesystem and lifecycle contracts. nrvna does not claim production readiness.

~/why

Built for interrupted time and finite machines

I built nrvna on a 2017 Intel MacBook while caring for two young children. I had little uninterrupted time or compute. I wanted to leave work in a folder. A local model could process it when the machine was available. I could return to the results later.

Local compute is finite and intermittent. Work should not disappear because the caller, model process, or terminal is gone.

~/primitives

Three binaries

  • nrvnadLoads one model and processes one workspace
  • wrkSubmits one job and returns its ID
  • flwReads workspace status and job results

That is the complete API. Applications compose text, vision, embedding, transcription, and speech jobs with files and exit codes.

~/how-it-works

Jobs are directories. State is location.

workspace/
├── input/ready/   queued
├── processing/    claimed
├── output/        results
└── failed/        errors

The workspace remembers. The model does not.

Transitions are atomic renames. No database. No message broker. No runtime dependency beyond the binaries and the models. Every job runs in a fresh context: bounded input, no session drift, inspectable output.

Jobs survive daemon restarts, closed terminals, and sleeping laptops. Results are plain files. cat them, grep them, pipe them into the next job.

~/where-it-fits

Bigger than one prompt, smaller than a framework

  • Not a chat app Independent jobs, not conversations
  • Not an agent framework Primitives that applications use
  • Not a model runtime llama.cpp runs the model. nrvna provides jobs and workspaces for application-side composition.
~/built-with-nrvna

A family of small, sharp apps

  • imgsrch

    Search your screenshots and images by what's in them. Fully local.

  • bckbrnr

    Local prompt work from the macOS menu bar. The answer is a file.

Each app bundles the primitives and adds no alternate inference path. The list is meant to grow.

~/agents

Give it the same three commands

Paste this into a coding agent with shell access:

Read https://raw.githubusercontent.com/sanmathigb/nrvna/main/AGENTS.md.
Explain nrvna's job, context, drain, and failure contracts before using it.
Use an isolated workspace and an existing local model. Do not download models
or modify existing workspaces without asking me first.

The agent still owns context selection, model routing, validation, and retries. nrvna keeps the inference work durable.

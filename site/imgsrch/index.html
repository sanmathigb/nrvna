workflow

Three commands

$ imgsrch init shots
$ imgsrch index shots ~/Screenshots/*.png
queued: 70 image(s) — indexing runs in the background. come back later.
$ imgsrch search shots "diagram explaining KV cache"
  • setupDownload the three pinned models — 3.4 GB, checksum-verified, once
  • initCreate a project
  • indexCopy images in, queue the reading; workers finish in the background
  • statusRead-only progress — what finished, what failed and why
  • searchNatural language in, ranked files with matched text out

Plus add, stop, and doctor. That’s the whole surface.

mechanics

How search works

index:   image ──► caption model ──► caption.txt ─┐
               └─► OCR model ─────► ocr.txt ──────┴─► combined.md ─► embedding.json

search:  query ──► embedding ──► cosine per image ──► dense ranks ─┐
         query ──► BM25 over combined.md ───────────► keyword ranks┴─► RRF

RRF is the default because it measured better on a labeled hard set. The previous scorer still ships, so the claim stays checkable.

no black box

The index is plain files

shots/.imgsrch/
├── artifacts/<image>/   caption.txt · ocr.txt · combined.md · embedding.json
├── index/index.tsv      the search index — a TSV you can read
└── workspaces/          the engine’s job queues, inspectable mid-flight

If a search result surprises you, the reason is a file you can open.

install

One archive, no dependencies

$ tar -xzf imgsrch-darwin-arm64.tar.gz
$ cd imgsrch-darwin-arm64
$ ./imgsrch setup   # fetches the pinned models, once
  • imgsrch-darwin-arm64.tar.gzmacOS 13.3+, Apple Silicon
  • imgsrch-darwin-x86_64.tar.gzmacOS 13.3+, Intel
  • imgsrch-linux-x86_64.tar.gzLinux x86-64, AVX2

Everything is bundled except the models. CPU-first, no GPU required. SHA-256 checksums ship next to each archive. macOS builds are unsigned; the first run may need approval in System Settings → Privacy & Security.

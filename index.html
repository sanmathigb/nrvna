MIT · open source · runs offline · old hardware OK

nrvna is a set of asynchronous inference primitives,

to make local AI durable.

Use them as-is, or build on top.

Text, vision, voice: inputs to the model are all just work. Run a daemon per workspace. Retrieve inference whenever you're ready.

Models get wrk. You get flw.

$wrk ./workspace "<prompt>"

Submit work to a workspace. No daemon needs to run.

$nrvnad ./model.gguf ./workspace

Start the daemon in the workspace. It runs the waiting job.

$flw ./workspace "$job"

Read the output like a file, whenever you come back.

workspace/

prompt.txt
↓
processing/

↓

Here it is, on a real laptop.

2017 Intel MacBook Pro, CPU. Three prompts typed in, the daemon runs them, then a result is read back by its ID, with no model running. The inference wait is cut and labelled.

Always in the workspace.

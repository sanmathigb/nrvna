/how-it-works

Three primitives. Fire and forget.

wrk, nrvnad, and flw are independent — run each anytime, anywhere, in any order.

$wrk ./workspace "<prompt>"

Submit work anytime — no daemon has to be running. It waits as a job.

input/ready/
job_id/
prompt.txt
$nrvnad ./models/model.gguf ./workspace

Start the daemon whenever, wherever. It claims the waiting job and runs it.

processing/
job_id/
prompt.txt
$flw ./workspace "$job"

Come back whenever and read the result straight off disk.

output/
job_id/
prompt.txt
result.txt

The model is a utility. Your work is central.

The work outlives the process.

Built on llama.cpp. Runs on ordinary, even old, hardware.

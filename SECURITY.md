# Security policy

Do not include private prompts, model files, workspace data, or credentials in
a security report.

Report a suspected vulnerability through
[GitHub's private vulnerability reporting](https://github.com/sanmathigb/nrvna/security/advisories/new).
Include the affected version, steps to reproduce, and the impact. Do not post
an unpatched vulnerability in a public issue.

nrvna runs local models and stores job data in workspace files. Apps that use
nrvna can add their own network access and data handling. Review each app's
behavior before sending it sensitive data.
